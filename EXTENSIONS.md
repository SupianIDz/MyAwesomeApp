# Extensions

Extensions that attach to another app. Standalone apps live in [README](README.md),
services that run on your own server live in [SELF-HOSTED](SELF-HOSTED.md).

> Rule: if a product has both an app and an extension version, keep a single entry
> in its primary location (usually `README.md`) + a browser badge instead of duplicating it here.

Badge rule: ![Chrome] means available as a browser extension or web version. Other browsers are not tracked separately.
