# My Awesome App

My Awesome App is a repository that contains a list of great apps that are worth using.

- [Apps](README.md) - Standalone apps (this file).
- [EXTENSIONS](EXTENSIONS.md) - Extensions that attach to another app (browser, editor).
- [SELF-HOSTED](SELF-HOSTED.md) - Services that run on your own server / Docker.

#### Placement rule (1 app = 1 entry, no duplicates)

1. Attached to another app? -> put it in `EXTENSIONS.md`.
2. Requires a server / Docker to run? -> put it in `SELF-HOSTED.md`.
3. Otherwise -> put it here (`README.md`).

If a product has multiple versions (desktop + browser extension, or self-host CE + Pro / Cloud),
keep a single entry in its primary location + mention the other versions in the description / badge.

Badge rule: ![Chrome] means available as a browser extension or web version. Other browsers are not tracked separately.
